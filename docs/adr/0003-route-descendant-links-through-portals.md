# ADR 0003：后代跨域关系通过入口球扎入

- Status: Accepted
- Date: 2026-07-21

## Context

跨域关系的远端节点不在当前域中。将关系线一律画到屏幕边界会让用户误以为关系没有明确去向；直接把后代节点投影到当前域又会破坏域层级。

## Decision

当关系远端位于当前域的后代域时，关系线连接到通往该后代域的第一个可见入口球。入口端点增加尺寸不超过球直径四分之一的小型深空漩涡，表示关系“扎入子域”，而不是与入口球建立普通同层关系。

祖先域、兄弟域或尚无可见入口的远端关系继续使用边界长尾。

## Consequences

- 用户能从当前视图判断关系进入哪个子域。
- 当前域仍只实例化本域节点，层级没有被压平。
- 普通同层关系保持原有实线语法。
- 多条关系进入同一入口时需要控制标签与端点密度。
