# ADR 0001：分离视觉交互层与业务数据层

- Status: Accepted
- Date: 2026-07-21

## Context

项目希望用三维空间替代表单与卡片交互，但三维呈现本身不应接管审批、权限、业务计算或数据流脚本。若视觉引擎直接解释业务字段，输入映射、空间旅行和业务状态会耦合，范式将无法跨项目复用。

## Decision

视觉层只处理相机、命中、空间结构、球镜、视觉编辑反馈和有限视觉意图。它通过 `spatial-visual-intent` 对外广播意图。业务脚本自行决定是否响应以及如何处理业务数据。

通用知识库节点、关系和详情可以由独立工作区模型保存，但这些字段不得被视觉层解释为具体业务流程。

## Consequences

- 同一套3D范式可以连接不同项目的数据脚本。
- 输入设备可以重新映射而不改变业务实现。
- 视觉元数据必须使用白名单，不能携带任意业务对象。
- 业务集成需要显式订阅意图，不能依靠引擎内部副作用。
