# ADR 0002：统一使用可进入的隧洞球载体

- Status: Accepted
- Date: 2026-07-21

## Context

早期方案区分实体球与隧洞球。实体球被理解为不可继续深入的终点，导致后续无法在其内部新增节点，也把数据当前状态误当成永久结构类型。

## Decision

所有载体统一为可进入的半透明隧洞球。`hasChildren` 只表示当前是否已有可展开的种子内容：有内容时可同层展开，没有内容时进入空子域并允许以后新增节点。

球镜是覆盖球体内部的独立展示层；隧洞属性始终由结构边界纹理表达，不由球面内容决定。

## Consequences

- 任何节点都可以在未来扩展子域。
- 当前空状态不再变成不可逆类型。
- 球镜、同层展收和沉浸进入保持职责分离。
- 旧实体节点导入时按空隧洞兼容，不需要第二套渲染路径。
