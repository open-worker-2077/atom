# Spatial KB CLI 实施计划

> 本计划在保留现有 3D 交互范式的前提下，补齐真实跨域编辑与知识库持久化。

## 任务 1：锁定跨域失败

- 增加回归测试，证明新域出现后 Ctrl 编辑不得被镜头缓动拦截。
- 增加入口版本测试，证明所有本地脚本和样式均带同一构建号。
- 拆分“场域不可编辑”和“镜头仍在缓动”两个状态。

## 任务 2：建立持久化核心

- 增加 JSON 模式、校验、原子写入和稳定身份工具。
- 覆盖节点增删改查、跨域关系、搜索、修订号和冲突校验。
- 为现有工作区模型增加显式导入与导出，不改变视觉生成职责。

## 任务 3：建立页面桥

- 页面在本地服务入口加载知识快照。
- 页面提交后同步完整工作区快照。
- 页面定期读取外部 CLI 更新，并在无活动编辑时刷新当前域。
- 页面上报当前域、可见节点、关系和镜头视图。

## 任务 4：建立全局 CLI

- 增加无依赖命令解析和结构化错误码。
- 增加 `spatial serve` 静态服务与本地 API。
- 安装为全局命令并验证命令发现、版本、诊断与 CRUD。

## 任务 5：联合验收

- 全量运行原有交互测试和新增持久化测试。
- 在页面完成跨域起点、进域、落脚、确认的完整操作。
- 用 CLI 读取同一跨域关系，再创建节点并在页面看到更新。
- 保存最终截图、控制台日志和全局安装位置。
