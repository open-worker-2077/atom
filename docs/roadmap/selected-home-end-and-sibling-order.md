## 已确认方向

- 未选中节点时：
  - `Home` 收缩到顶层 Boss。
  - `End` 从顶层 Boss 开始展开。
- 选中节点时：
  - `Home` 以选中节点作为收缩终点。
  - `End` 以选中节点作为展开起点。
- A、S、D 应分别按外围、嵌套、层级语法显示展开结果。
- F 无法同时沉浸多条分支；未来沿每层排序第一的子节点下钻至叶子。

- 当前系统只有飞书视图行顺序、导入创建顺序和 JSON 数组顺序形成的隐式顺序，不能作为长期语法。
- 需要确定飞书字段、JSON 字段、编辑交互、重排规则以及重新导入时的稳定性。
