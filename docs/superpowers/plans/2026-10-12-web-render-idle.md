# Web 空闲绘图与跨页面卡顿

> **For agentic workers:** Use superpowers:executing-plans inline; fresh whole-branch review before delivery.

**Goal:** Atom 开着但未操作时不持续重画，后台停止绘图，操作与外部更新仍及时显示，降低对其它页面的影响。
**Architecture:** 在既有渲染循环内管理绘图需求，复用输入、相机动画、演示和数据更新入口；不另建服务，不重启健康后端。
**Tech Stack:** Canvas 2D、JavaScript、Playwright、Node。
**Spec:** 用户确认关闭 Atom 后其它页面立即不再卡顿；沿用已确认的空闲/后台降开销、交互与数据更新及时响应主干。

## 排查假设

1. 空闲持续重画和高分辨率模糊绘制竞争共享绘图资源：暂停空闲绘图后绘制次数应归零。
2. 数据/布局/Markdown重复计算形成主线程长任务：复杂 fixture 的回调计时可区分。
3. 初始加载瞬态与稳定场景不同：分别报告稳定计时，不用初始化数值夸大结论。
