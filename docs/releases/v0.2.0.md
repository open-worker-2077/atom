# graph-4d v0.2.0

这是 `graph-4d` 的首个正式 GitHub Release，也是当前已验收的多球域知识库试点基线。

## 这次发布包含

- 以无中心多球域、递归隧洞、三维视角和节点网络替代表单／卡片导航。
- 区分使用、游走、展收和球镜观察，物理按键通过可配置映射连接视觉意图。
- 支持节点与关系编辑、空间搜索、跨域落脚、历史长尾和本地持久化。
- 跨域后代关系会进入对应入口球，并用小型深空漩涡表达“扎入子域”。
- 提供全局 `spatial` CLI、本地服务和共享的 `data/knowledge.json` 存储接口。

## GitHub 治理

本次同时建立 GitHub 原生项目结构：贡献指南、架构文档、ADR、Issue Forms、PR 模板、自动化测试和 Release 记录。新 Agent 以最新 Release、`main`、开放 Issues 和 PR 为事实源，`AGENTS.md` 只负责提供读取顺序。

## 数据边界

3D 引擎继续只负责视觉交互，不承担业务计算或数据流脚本。`data/knowledge.json` 是本机运行数据，已退出 Git 跟踪；本次发布不包含用户知识内容。
