## Result and boundary

- `executeAtomLanguageInteraction` prepares the complete Transform-compatible match list for a pure Explore, but does not build Transform's exact selector index or capture partner bindings. A real Transform still calls `prepareTransformRelationIndex` at the request boundary and completes both products.
- The match-list-only state shares the existing sealed-world `preparedTransformRelations` WeakMap. It is never retained for unsealed or shallow-frozen facts; a later Transform reuses the root-independent matches and builds root-dependent bindings. Existing inherited relation state is retained when adding matches; a matches-only entry cannot stand in for completed bindings.
- The existing Explore prepared match list is not a drop-in access-controller input: it adds a virtual `世界之外` before a real Agent of the same name, and renders a missing-thing ancestor as `[index]` where Transform's path contains `undefined`. The focused test demonstrates a different authorization decision for the virtual-root collision. This change keeps the prior Transform DFS match shape and path ordering, including unusual inputs.
